# MPWindows CRM — Flutter MVP

CRM MVP cho MPWindows: quản lý khách hàng, hành trình bán hàng, công việc, lịch hẹn và xuất Excel.

## Chạy local
```bash
flutter pub get
flutter run
```

## Build iOS
```bash
flutter build ipa --release
```

Build/sign IPA cần macOS/Xcode và Apple Developer.
